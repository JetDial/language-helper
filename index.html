Getting real voices

A web page can only use voices the computer already has, so this is the one thing the site cannot do for you. Both routes below are free.

Windows — Settings → Time & language → Language & region → Add a language. Pick the language, and on the options screen tick Speech. Then restart the browser. The newer "Natural" voices sound genuinely human.

Chrome — Google ships its own voices for dozens of languages and they need no installing at all. If a language shows as missing here, try opening this page in Chrome before installing anything.

Android / iOS — the system already carries many languages; add more under accessibility or language settings.
